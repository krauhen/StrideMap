# MCP guidance

## Status

No project-specific MCP server, browser, map, or Android automation MCP workflow is currently required for StrideMap v1.

## Usage boundary

- Prefer repository files and the standard Gradle/ADB commands in `SETUP.md` and `TESTING.md` for local validation.
- Use external MCP/docs tools only when a task needs current third-party documentation or explicit browser/device automation.
- Do not add MCP servers, credentials, generated config, or tool-specific artifacts without explicit approval.
